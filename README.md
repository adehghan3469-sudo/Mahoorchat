# 🌾 داشبورد گزارش روزانه کشاورزی بابامنیر

داشبورد تعاملی برای نمایش گزارش روزانه هواشناسی، قیمت نهاده‌ها و توصیه‌های فنی کشاورزی منطقه **بابامنیر** و اطراف آن (نورآباد ممسنی و ماهور میلاتی).

---

## ویژگی‌ها

- هواشناسی زنده از Open-Meteo (بدون نیاز به API Key)
- نمایش دما، رطوبت، باد، احتمال بارش، ET₀ و شاخص UV
- پیش‌بینی ۷ روزه + پیش‌بینی ساعتی
- مقایسه سه منطقه تحت پوشش
- توصیه‌های فنی پویا بر اساس شرایط هوا
- پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)

---

## اجرا محلی

```bash
pip install -r requirements.txt
streamlit run babamenir_dashboard.py
```

---

## استقرار روی Streamlit Cloud

1. این مخزن را در [Streamlit Community Cloud](https://share.streamlit.io) انتخاب کنید.
2. Main file path را روی `babamenir_dashboard.py` قرار دهید.
3. Deploy کنید.
